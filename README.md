# 📚 Libris System

## 📌 Overview
Libris System is a Java-based library management system that allows users to manage digital content, track reading progress, handle payments, and interact with a structured database.

This project was developed as part of academic coursework for software design and database integration.

---

## ⚙️ Features
- User account management
- Book catalog and bookmarking system
- Reading progress tracking
- Payment and subscription handling
- Database connectivity using PostgreSQL
- Modular DAO (Data Access Object) structure

---

## 🛠️ Technologies Used
- Java (JDK 21)
- Eclipse IDE
- PostgreSQL
- JDBC (Java Database Connectivity)
